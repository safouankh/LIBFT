# LIBFT

A foundational C library project from the 42 curriculum. It reimplements common standard-library functions and adds utility functions for working with strings, memory, characters, and file descriptors.

## Build

```sh
make
```

The Makefile builds the library archive. Include `libft.h` in your project and link the generated library when compiling. Use `make clean` or `make fclean` to remove build artifacts if those targets are available.

See `libft.h` for the available function declarations.
